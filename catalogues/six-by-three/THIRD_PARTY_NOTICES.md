# Mathematical and implementation notices

The catalogue definitions and historical theorems are credited separately
from the project's code and certificates. See [PROVENANCE.md](PROVENANCE.md)
and the file-level [source record](PROVENANCE.json), together with
[HISTORY.md](HISTORY.md).

`common/positive.py` and `common/quadratic.py` adapt the user-organized
predecessor project's exact interval and quadratic-field implementations.
Their original member names, input hashes and current file hashes are
recorded explicitly. The former generic "Bell Exact Bounds Project"
description denotes these contributor-confirmed local artifacts; it does
not identify a separate external software project. The two Gram JSON files
likewise retain exactly specified fields from the predecessor certificate
corpus.

This catalogue requires only the Python standard library and does not
bundle an upstream scientific software distribution. Mathematical formulas
and theorem references retain their scholarly attribution. The repository
license does not relicense the cited papers, their prose, figures, typeset
tables or source archives. No full external article is distributed here.
