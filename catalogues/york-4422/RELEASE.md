# Version 1.0.0 — Exact Quantum Suprema and Certificates for the York (4,4,2,2) Bell Catalogue

This is a constituent catalogue overview for version 1.0.0 of **Exact Quantum Suprema and Certificates for Selected Bell Scenarios**. Use the combined [release description](../../RELEASE.md), [publication instructions](../../UPLOAD.md) and [citation metadata](../../CITATION.cff) when publishing or citing this edition. The local `CITATION.cff` records constituent provenance.

This constituent catalogue presents the 175 inequivalent CH probability facets of the (4,4,2,2) local polytope in their original York order. Each number has its own coefficient table and an explicit signed map to a traditional representative. A solved entry includes the analytic value, its unrestricted upper argument and its physical attaining or approximating construction. All mathematical inputs are distributed with their entry.

The finite-attainment proofs cover 170 entries. I3322 has a path-defined supremum and an explicit family of finite strategies approaching it, both treated in the local proof; normal infinite-dimensional attainment and finite-dimensional nonattainment are attributed to the detailed cited theorems. Y83, Y92, Y125 and Y128 have unknown exact unrestricted quantum suprema. Overlap with another catalogue never removes an entry from this release.

The York order follows the 175-class list of Cope and Colbeck. Signed permutations, party exchange when needed and an explicitly stated normalization identify each traditional label. The historical exact results include Cirel’son’s CHSH bound, Ben Li’s two four-setting correlation facets and recent independent work on I3322. Each implicit algebraic certificate specifies a physical state and its measurements at an isolated root and pairs that construction with a dimension-independent upper proof. The historical guide distinguishes classical enumeration, numerical optimization, public computational contributions and earlier proofs of an exact value.

**Using this release.** Start with `INDEX.md`, then open the numbered folder. Read `PROOF.md` for the argument and `definition.json` for the original CH coefficients. Run `python verify.py 25` for a compact example. To inspect an algebraic certificate, run `python verify.py 7 --extract Y007-proof`. The reference system uses a separately installed CPython 3.12 x64 on Windows x86-64. The mathematical inputs, calculation libraries and entry-local C99 interval verifier sources and executables are included. The numerical environment includes the documented local binary64 NumPy build and SciPy; its licenses and sources are supplied. No PowerShell/.NET distribution or MSVC runtime DLL is bundled. `MANUAL.md` gives worked examples, `HISTORY.md` provides the bibliography and `DISTRIBUTION.md` explains the offline volumes. For the complete combined distribution, follow the root [distribution instructions](../../DISTRIBUTION.md): extract every ordinary release volume into the same empty directory, or use the complete master ZIP. These ordinary volumes are not the ordered binary certificate parts within individual entries.
