# Citation and archiving

Cite Yang-Guang Yang, *Exact Quantum Suprema and Certificates for Selected Bell Scenarios*, version 1.0.0, using the combined repository's [CITATION.cff](../../../CITATION.cff). It supplies the author name, ORCID and contact email. This catalogue's [local citation metadata](../CITATION.cff) records its constituent title and provenance; it is not a separate release citation. Also cite the original catalogue and any earlier mathematical proof credited in the relevant class.

Publish and archive the combined repository according to [UPLOAD.md](../../../UPLOAD.md), using the root [release description](../../../RELEASE.md). Retain this catalogue within `catalogues/sliwa-46/`. No separate repository, release tag or DOI is required for the constituent catalogue.

No DOI is assigned by preparing these files. When obtaining one, archive the complete combined distribution, including every certificate and runtime payload, and use only the identifier actually issued for that deposit. GitHub's automatic source archive alone omits large York inputs and is not the complete proof distribution. Follow the root upload instructions for incorporating an issued identifier and regenerating manifests. Use a version DOI to identify the exact archived edition; a concept DOI identifies the family of releases.
